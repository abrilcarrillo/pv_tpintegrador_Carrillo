## Descripcion TP Integrador - 2026

Este proyecto consiste en la construcción de un Panel de Control de Clientes utilizando React y Vite. La aplicación permite gestionar y visualizar información de clientes mediante el consumo de datos de la API pública FakeStoreAPI, además de navegar entre distintas vistas.

Se utilizan tecnologías como React Router DOM, Context API, LocalStorage, Axios y React Bootstrap.

Se realizaron modificaciones:

Se implementaron las rutas utilizando createBrowserRouter.

Se trasladaron las validaciones del Login a autorizacionesServices.js.

Se agregaron validaciones personalizadas en JavaScript al formulario de clientes.

Se organizaron las funciones para obtener, crear y eliminar clientes dentro de clientesService.js.

Se realizaron ajustes en el Dashboard y en la protección de rutas.
